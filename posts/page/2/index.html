2025-09-27 技术前端问题解决

React的useLayoutEffect使用

问题背景 这周在帮助b哥完成他的项目前端的时候遇到了一个有趣的问题。 先介绍下背景，这是一个企业内即时通讯工具，主要的页面布局，从上往下依次包括消息列表、选择面板、操作栏、输入框。 初次尝试：DOM结构调整 在一开始的时候，b哥提出的问题在于如何修改CSS让选择面板正确的渲染到操作栏的上方而不是下面。 这个我想到的当然是直接修改dom结构，何必要用CSS来实现呢，很快就实现了这个需求。 隐藏的挑战：异步渲染顺序 然而在之后却发现了新的问题，因为选择面板和消息列表的加载其实是依赖于API的。在当时我们反复测试的情况是，操作栏先渲染成功，然后是消息列表，最后是选择面板。 对于除了消息列表之外的其他组件，其实是会占据空间然后导致消息列表的可见范围越来越短的。 在操作栏渲染之后，消息列表才开始渲染，一切都显得很正常。而当选择面板出现的时候，消息列表的高度变小了，但是内容却没有维持在最新的位置。 尝试CSS解决方案 这个问题看起来很简单的。b哥要求使用css来完成这个任务，询问AI之后，给出的是flex的column-reverse方案，这个方法看起来可行，实际上却并没有解决问题。 回顾现有代码：JavaScript解决方案 当重新阅读代码的时候，发现其实之前的代码使用了一个Javascript方法，在数据加载完成后，手动调用面板的ScrollIntoView方法，以适应高度的变化。 那么使用纯CSS就没法实现这个功能了，因为这个方法已经在多个地方使用，我们只能继续在合适的地方继续使用而不是自己新建一套CSS方案。 脱敏示例代码如下 function recalcposition() { setTimemout(() => { panelRef.current.scrollIntoView({ behavior: "instant", block: "end" }); }, 50) } 探索DOM观察者API 一开始我想的是能否找到一个onResize的事件来监听页面的变化，但是实际上React似乎并没有封装这么一套系统，而我又不想使用原生的接口，于是乎想到了IntersectionObserver类似的DOM接口。 AI推荐了ResizeObserver/MutationObserver。当使用ResizeObserver时，我们发现成功了，但是却发生了新的问题： 新问题：渲染延迟 每一次都是选择面板渲染成功之后，经过了一个定量的延迟，消息面板才会滚动到最新的底部位置。 这个问题可把我们难到了，尝试MutationObserver或者去掉recalcposition的延迟都没有什么效果。 也许只能这样了？ 思考的时间 我下楼抽了根烟，在考虑为什么会发生这个延迟。 React渲染机制的启示 当想到之前看过的React渲染机制的时候，猛然想到，在React中，无论如何，这些浏览器API生效的时候都在Commit阶段之后。 那么只有等到下一次React渲染的时候，新的位置才会生效。为了把这次调整操作提前，是否可以使用useLayoutEffect这个Hook，在提交到DOM之前调整其位置。 最终解决方案：useLayoutEffect 我立即回来尝试了一番， useLayoutEffect(() => { panelRef.current.scrollIntoView({ behavior: "instant", block: "end" }); }, [someVarToShowChoosePanel]); 这里的someVarToShowChoosePanel 是用来控制选择面板的显示与隐藏的状态。 果不其然，延迟消失了。 总结 useLayoutEffect 与普通的 useEffect 相比，最关键的区别在于它的执行时机。它会在DOM变更后、浏览器绘制前同步执行，这使得它特别适合于需要直接操作DOM并且希望避免视觉闪烁的场景。 在我们的案例中，这正是解决渲染延迟问题的关键 - 确保滚动操作发生在浏览器绘制之前，而不是之后。这种精确的时机控制是React hooks提供给我们的强大工具之一。

2025-08-26 博客技术心情

用AI重构我的blog

AI助手如何帮我重构博客 今天，我决定借助GitHub Copilot的能力来重构我的博客。作为一个技术博客，我一直觉得它缺少一些结构性的元素来帮助读者更好地浏览内容。通过与AI助手的对话，我完成了一系列改进，现在记录下这个过程。 添加标签系统 我的博客最大的问题是缺乏良好的内容分类。虽然文章按时间顺序排列，但读者很难找到特定主题的内容。 为所有文章添加标签 首先，我让AI助手为所有博文添加了合适的标签。经过分析我的文章内容后，AI助手设计了一个包含以下主要分类的标签系统： 生活相关：生活、日常、家庭、心情 个人成长：个人成长、感悟、思考、回忆 技术相关：技术、前端、问题解决、教程 兴趣爱好：读书、游戏、影评 其他：工作、博客 每篇文章都被赋予了2-3个最相关的标签，使内容更易于分类和发现。 创建标签导航页 为了让读者能够轻松浏览不同类别的内容，我创建了一个专门的标签页，组织了所有标签并提供了简短的描述，帮助访问者理解每个标签所代表的内容类型。 将标签页添加到主导航 为了让标签系统更容易被访问到，我在网站的主导航菜单中添加了一个"标签"链接，使用了Font Awesome的标签图标使其在视觉上更加直观。 清理博客内容 除了添加标签系统外，我还： 删除了所有标记为草稿的文章，确保只有完成的内容被展示 简化了标签系统，移除了冗余的标签 统一了文章的元数据格式，使博客整体风格更加一致 收获与体会 这次借助AI重构博客的经历让我意识到，技术不仅可以用于创建内容，也可以帮助我们更好地组织和展示内容。通过几个简单的对话，我的博客获得了以下改进： 更好的内容导航 - 读者现在可以通过标签快速找到感兴趣的主题 更清晰的内容结构 - 移除了草稿内容，使发布的文章质量更高 更一致的元数据格式 - 标准化了所有文章的前置信息 这种结构化的改进不仅对读者有利，对我自己也是有帮助的。当我继续写作时，这个标签系统将帮助我思考文章的分类和主题，使我的博客内容更加有条理。 未来计划 在这次重构的基础上，我计划继续改进我的博客： 可能考虑按标签或主题组织一些精选文章合集 进一步优化博客的视觉设计，使其更加现代化 添加更多互动元素，如评论系统和社交分享功能 通过这次重构，我重新认识到了博客作为个人表达和知识分享平台的价值。希望这些改进能让我的内容对读者更有帮助，也能激励我继续写作和分享。 感谢GitHub Copilot的协助，让这次重构变得简单而高效。技术的进步确实为内容创作者带来了新的可能性。 这篇blog完全由Copilot生成。

可当我真的玩到大后期的时候，才发现自己居然有一个存档已经打到了称王称帝的阶段。自己是什么时候玩的这个呢？我怎么不记得了呢！ 趁着春季大促，我入手了星露谷物语，自己在周末的时候玩了个两三个小时，那天觉得还不错，但是等后面再想玩游戏的时候，却没有那个心思继续玩下去了。这个游戏弟妹在后面入手了，已经玩了一百多个小时，我没想到她会喜欢马赛克游戏，让我推荐一些游戏，按照之前玩过的那些类似《植物大战僵尸》、《杯杯倒满》的风格，真的是想不出来。 杯杯倒满 说到杯杯倒满，这个开奶茶店的游戏。恰恰和最近的manner咖啡店事故让人觉得细思极恐。manner的咖啡店员工却是像是压力爆炸的小熊小狐狸一样，而一个店面日销售额不够5000元的情况下只配备一名员工，可没有其他员工给你安抚情绪，给你搭一把手拉你起来。 等我完成了第一个阶段的杯杯倒满游戏之后，就弃坑了这个游戏。谁也不想在白天打一份工，下了班再打一份吧？ DNF手游 我在游戏出阿修罗职业之后，又重新来玩了。等自己真的氪了一点金，又发现这个真的是个无休无尽的坑。提升是没有止境的，玩这种数值游戏只能获得空虚，空虚和空虚。 艾尔登法环DLC 等到6月底，终于迎来了法环DLC的发布，意料之外的是老婆对DLC似乎更加有热情。在前期帮我探图、推剧情，帮我打了牢大、满月骑士等boss，甚至还帮我剪了几个直播视频上传到B站上去。 但是不得不承认自己在有段时间还是有点厌倦这个DLC的。毕竟劳资已经一周目当过王的男人了，为了进入DLC也鸭子乐秒了蒙格，一路过关斩将来这儿的，却被幽影地的小兵砍的抱头鼠窜，实在是让人不爽。 等到过了一个星期之后，自己终于推进主线到了拉塔恩，然后就被对方无休止的疯狂进攻打懵了。不是很习惯这种连续四连、五连甚至七八九十连招攻击的boss。然后就转身投入了洗点、寻找轮椅逃课的道路。 找了拒绝的刺，放弃了癫火调香瓶、试了各种武器和各种大哥，终于还是选择了盾戳流派。发现自己有指纹盾，也发现自己没有黄金粪金龟（因为在小号上），真的可能盾戳就是给我的最好选择吧。 然而我却忘记了强化满级我的盾戳，以至于上周四晚上打了几个小时都各种功亏一篑。因为没有防御强度，每次拉塔恩急风骤雨的攻击，都打的我喘不过气来。等我下播之后，才想起自己没有强化盾牌到满级这个事情。 磨磨唧唧到周五之后，自己强化了满级盾牌，果然打了十来把就过了。然后号也已经被我洗的面目全非了。现在变成主力量的小水桶号了。 运动 羽毛球 Early 2024-04-07 生活日常回忆思考感悟

2024第一季度总结

按理来说，大家都会在年底的时候写一个年度总结，但是等我想起动笔的时候，现在已经4月份了，实在是有些晚了。2023年年度总结现在来做有些晚了，而且恐怕内容很多，写太多又耗费时间，写太少又会变成记流水账。不如写一篇季度总结，可以细致一些，又不会太耗费精神。 1月 我的思路是翻看自己两个手机上的照片，结果翻了两遍都没发现一月份有什么特别重要的事情。 不过也没什么问题，也许人生就是需要一段时间的蛰伏呢。（自嘲） 现在我的工作形成了每天固定的节奏还是不错的。每天下午6点钟，如果Roger在，他会和我讨论一些各个方面的他的观点。 之前他会给我提的问题，被我称为“婚房育”三连击。去年我结婚了，现在就是什么时候生孩子？什么时候买房？我家附近的房子跌了，要不要考虑入手一个？ 当然他也提过很多其他引人深思的话题。比如，看我有时候在想如何赚钱，他提出让我去看国家的进口限制目录。这里的清单上面都是国家急需的产业，做起来肯定有政府政策支持。我说：这是我一个人该想的吗？那不是大企业、大制造业、大资本才会去考虑的问题吗？我一个人又没资本，又没这方面的本事，怎么做的来？ 他后来又说，当今的社会，其实我们是可以成为内容生产者的。因为一个有不少粉丝的up主，照顾自己的基本盘，就可以温饱，养活自己的家庭。我说：你展开说说呢？ 他说：凡事能在大城市立足的人，多少是有点本事在身上的。你考虑下自己最近三年内做过的，反复成功过三次以上的事情。这些都可以拿来做你的优势，来做你的内容。只要你找对了方向，大家喜闻乐见的优质内容生产者还是有很多机会的。 我想了好几次，也没想到这个自己最近三年反复成功过三次以上的事情是什么。很困扰。想来最近也没有很成功的事情。成功结婚？这个一辈子一次也就够了啊哈哈哈。 2月 相对来说，2月份的生活就丰富多了。因为在过年期间，有机会看了两部春节档电影，去了一次东营。 第一部看的是《飞驰人生2》。之前我也看过第一部，但是说实话已经不记得了，毕竟我脑子里不怎么记电影。在看2的时候不断的提醒，我才想起来一些。当时看完觉得还不错，有细节，故事过程和结局也设计得合情合理，不会让人觉得突兀。 然后一周我们就看了《第二十条》。哇，这个电影才是春节档的重磅作品吧！我想关于公平，基于社会真实状况的好电影永远要让人觉得震撼和共情吧！看完这个就想，嗨，这春节档三部电影看了两部 还真是给我看对了。（笑） 2月份在老家过年之后，就去了一趟东营，这是2011年夏天去东营之后，时隔13年，又去的东营。也许是时间太长了，也是当时是夏天去的东营。现在发现和我记忆里还是差别很大的。冬天的风有时候很大，大到我在姐姐家的小院子里抽烟都是风抽一半我抽一半。大风刮的院子里的帐篷呼啦啦的。而过了一天，风停了，这里却又像另一个地方了。在镇上溜达的时候，确实发现有的地方很熟悉。像是我们去的那个公园，是13年前我曾经溜达过的地方，但是说实话只是记起有这个地方，不记得具体的内容。小外甥女走了一半就累了，最后让她爸扛了一路扛回来的，可真是“坑爹”。 重返上海之后，和老婆去了一次KTV。这次在KTV意外发现了几首自己唱的还不错的歌。比如刘德华的《冰雨》、花儿乐队的《忘不了》、许巍的《蓝莲花》，还有一首什么来着？《向天再借五百年》？哈哈哈哈 这个月看了一本书《邻家的百万富翁》，写了几篇公众号文章，但是却太干货，没有什么自己的想法。现在看来总结，这本书推荐的一个方法就是，“省钱”。在有能存下钱的收入之后，就是把钱存下来才能致富。剩下的就是在各个方面考虑如何省钱，比如，不要把自己拥有的物品的当作自己的价值，人不会因为用更加昂贵的包，买更加昂贵的汽车而让自己更有钱。同样也包括对子女的教育，让他们财务独立而不是成为自己的拖油瓶。 3月 3月份的故事也不少，这个月有个周末我租了一辆车，带着老婆和老丈人在市内旅行。去了复旦的江湾校区溜达，中午吃完饭之后想去共青森林公园。结果在那附近转了几个圈也没发现停车的地方，各个地方都是要排队，在一条很窄的路上掉头的时候还撞上了路边的一个消防栓，给车头一个地方都撞成红色的了。后来想了想算了，就回家了。等我还车的时候才发现，右边车后门被刮了！与老婆聊了之后，才知道我取车之后去接他们的时候（11时）就已经刮了，可是提车的视频（店员摄于9时）却没有这个痕迹。最后因为买了保险，让一嗨租车他们去处理了。 这个月，看了《周处除三害》。看完之后觉得，这个才是吊打所有春节档的电影。要是春节档进来，岂不是杀疯了。。。如果非要说有什么缺点，也许是中间的部分节奏太长了，让人看到陈桂林在教堂入教的时候觉得怀疑人生，难道这个是宗教宣传片？等到后面小孩妈妈经历了同样的事情的时候，才让人恍然大悟，也该开始真正的复仇了。我想，关于公平，基于现实的好电影永远让人关注，那么关于复仇、关于英雄的电影也永远扣人心弦吧！ 这个月关于学习的事情还是有一些的，半夜睡觉前，才想到BEC（商务英语）报名要截止了，和老婆说要不要报呢？还是再等下半年？最后决定掷个骰子，单数就报，双数睡觉。然后单数，于是爬起来重新打开电脑，报名了BEC Vantage。 这个时候我还没考完老板要求考的ASTQB，但是却提前给自己上了一个新目标，是不是有些不自量力了？ 等到3月30日，自己考完ASTQB的时候，真的是松了一口气，让自己高兴了一个多星期。这提醒了我自己在学习那些不感兴趣，打心眼里觉得没有用的知识的时候，还是看不进去。考前那几天真的是人麻了，考完之后，发现好像也就是那么回事。 这个月最大的事情，当然是发现老婆怀孕了。这件事给我的是7分惊喜和3分忧虑。对于以后如何赚钱的想法，又开始浮现。
