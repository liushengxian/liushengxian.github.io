2025年终总结

到了该进行2025年终总结的时候了。 前面大半年是继续当“厅长”的日子。因为儿子的出生，家里额外请了月嫂/育儿嫂。家里在黄浦区租的2室1厅小房子，岳父住次卧，母子和月嫂/育儿嫂住主卧，我只有客厅沙发可以休息。从孩子出生到8月初，在客厅沙发住了大半年多的时间。岳父把沙发的一边扶手放倒，还给我把显示器放到脚边的墙上，似乎真的有点像酒店客房的样子。 我一直觉得睡个沙发也没啥问题，直到几个月后有次落枕，发现确实是不那么舒服的。周末有时候没什么办法，只能找个几十块钱的钟点房睡大觉好好休息一下。最痛苦的一天，莫过于三月中的时候，不记得因为吃了什么导致的牙痛，疼了整整一晚，我大约只睡了一个小时，最后还是被疼醒。于是第二天一大早就和公司请好假，去了黄浦区牙防所，第一次遇到的年轻医生告诉我，只能开点止痛药，回去等牙神经完全坏死，就可以来拔牙了。”这个牙已经没有补的价值了”。但是那天下午我才知道，真正的牙髓坏死，是没有办法止痛的。不论是医生开的药还是老婆给的布洛芬，又或者物理的其他方法，都在自己躺下准备休个午觉时通通无效。无奈，我只能再次去了牙防所。这次我刚进门，对新医生说的第一句话就是，“我要把牙髓敲掉“。所幸，这次终于遇到优秀的王医生，帮我止痛之后开始补牙。当她把我的牙髓放掉之后，我终于舒服了。当时就想到电影《周处除三害》里，陈桂林从邪教中逃出，在船上呼吸自由空气的那个神态。 于是开始了上半年的漫长的补牙过程。算是把自己的一口坏牙都修修补补了。 可能是因为空间太小的原因，也可能是当了爸爸之后很少有自己一个人呆着的时间了，时间长了，有时候会觉得心情低落。在没有娃之前，我有时候会和老婆说，周末让我独处一段时间。但是这个时间可能在孩子出生之后很难保证了。但是，当察觉到自己的情绪的时候，我也要感谢妻子的理解和支持，允许我自己出去溜达放松心情，或者出门去上网。 如果没记错的话，上半年去网吧玩了一段时间的DNF，一直到19周年庆（也就是6月底7月的时候）。后来加入了蠢猫的网友群，认识了几个新朋友，开始和他们一起在祖安区玩大乱斗。就慢慢把DNF抛弃了。年初的时候还有段玩炉石传说的日子，后面也被抛弃了（两个月一个小版本，四个月一个大版本又要重新充钱）。但是开黑的时候，本来可以打出不错表现的我后来慢慢变菜了。于是乎11月底的时候自己用adc重新单排在祖安区上了一波黄金，“感觉好像上分也没那么难呢”。等我发表这番暴论之后，zhiyuan邀请我去征服之海区一起组排。打了半个月，只帮他们提升了一个小段位。（白银3 2025-09-27 技术前端问题解决

React的useLayoutEffect使用

问题背景 这周在帮助b哥完成他的项目前端的时候遇到了一个有趣的问题。 先介绍下背景，这是一个企业内即时通讯工具，主要的页面布局，从上往下依次包括消息列表、选择面板、操作栏、输入框。 初次尝试：DOM结构调整 在一开始的时候，b哥提出的问题在于如何修改CSS让选择面板正确的渲染到操作栏的上方而不是下面。 这个我想到的当然是直接修改dom结构，何必要用CSS来实现呢，很快就实现了这个需求。 隐藏的挑战：异步渲染顺序 然而在之后却发现了新的问题，因为选择面板和消息列表的加载其实是依赖于API的。在当时我们反复测试的情况是，操作栏先渲染成功，然后是消息列表，最后是选择面板。 对于除了消息列表之外的其他组件，其实是会占据空间然后导致消息列表的可见范围越来越短的。 在操作栏渲染之后，消息列表才开始渲染，一切都显得很正常。而当选择面板出现的时候，消息列表的高度变小了，但是内容却没有维持在最新的位置。 尝试CSS解决方案 这个问题看起来很简单的。b哥要求使用css来完成这个任务，询问AI之后，给出的是flex的column-reverse方案，这个方法看起来可行，实际上却并没有解决问题。 回顾现有代码：JavaScript解决方案 当重新阅读代码的时候，发现其实之前的代码使用了一个Javascript方法，在数据加载完成后，手动调用面板的ScrollIntoView方法，以适应高度的变化。 那么使用纯CSS就没法实现这个功能了，因为这个方法已经在多个地方使用，我们只能继续在合适的地方继续使用而不是自己新建一套CSS方案。 脱敏示例代码如下 function recalcposition() { setTimemout(() => { panelRef.current.scrollIntoView({ behavior: "instant", block: "end" }); }, 50) } 探索DOM观察者API 一开始我想的是能否找到一个onResize的事件来监听页面的变化，但是实际上React似乎并没有封装这么一套系统，而我又不想使用原生的接口，于是乎想到了IntersectionObserver类似的DOM接口。 AI推荐了ResizeObserver/MutationObserver。当使用ResizeObserver时，我们发现成功了，但是却发生了新的问题： 新问题：渲染延迟 每一次都是选择面板渲染成功之后，经过了一个定量的延迟，消息面板才会滚动到最新的底部位置。 这个问题可把我们难到了，尝试MutationObserver或者去掉recalcposition的延迟都没有什么效果。 也许只能这样了？ 思考的时间 我下楼抽了根烟，在考虑为什么会发生这个延迟。 React渲染机制的启示 当想到之前看过的React渲染机制的时候，猛然想到，在React中，无论如何，这些浏览器API生效的时候都在Commit阶段之后。 那么只有等到下一次React渲染的时候，新的位置才会生效。为了把这次调整操作提前，是否可以使用useLayoutEffect这个Hook，在提交到DOM之前调整其位置。 最终解决方案：useLayoutEffect 我立即回来尝试了一番， useLayoutEffect(() => { panelRef.current.scrollIntoView({ behavior: "instant", block: "end" }); }, [someVarToShowChoosePanel]); 这里的someVarToShowChoosePanel 是用来控制选择面板的显示与隐藏的状态。 果不其然，延迟消失了。 总结 useLayoutEffect 与普通的 useEffect 相比，最关键的区别在于它的执行时机。它会在DOM变更后、浏览器绘制前同步执行，这使得它特别适合于需要直接操作DOM并且希望避免视觉闪烁的场景。 在我们的案例中，这正是解决渲染延迟问题的关键 - 确保滚动操作发生在浏览器绘制之前，而不是之后。这种精确的时机控制是React hooks提供给我们的强大工具之一。

AI助手如何帮我重构博客 今天，我决定借助GitHub Copilot的能力来重构我的博客。作为一个技术博客，我一直觉得它缺少一些结构性的元素来帮助读者更好地浏览内容。通过与AI助手的对话，我完成了一系列改进，现在记录下这个过程。 添加标签系统 我的博客最大的问题是缺乏良好的内容分类。虽然文章按时间顺序排列，但读者很难找到特定主题的内容。 为所有文章添加标签 首先，我让AI助手为所有博文添加了合适的标签。经过分析我的文章内容后，AI助手设计了一个包含以下主要分类的标签系统： 生活相关：生活、日常、家庭、心情 个人成长：个人成长、感悟、思考、回忆 技术相关：技术、前端、问题解决、教程 兴趣爱好：读书、游戏、影评 其他：工作、博客 每篇文章都被赋予了2-3个最相关的标签，使内容更易于分类和发现。 创建标签导航页 为了让读者能够轻松浏览不同类别的内容，我创建了一个专门的标签页，组织了所有标签并提供了简短的描述，帮助访问者理解每个标签所代表的内容类型。 将标签页添加到主导航 为了让标签系统更容易被访问到，我在网站的主导航菜单中添加了一个"标签"链接，使用了Font Awesome的标签图标使其在视觉上更加直观。 清理博客内容 除了添加标签系统外，我还： 删除了所有标记为草稿的文章，确保只有完成的内容被展示 简化了标签系统，移除了冗余的标签 统一了文章的元数据格式，使博客整体风格更加一致 收获与体会 这次借助AI重构博客的经历让我意识到，技术不仅可以用于创建内容，也可以帮助我们更好地组织和展示内容。通过几个简单的对话，我的博客获得了以下改进： 更好的内容导航 - 读者现在可以通过标签快速找到感兴趣的主题 更清晰的内容结构 - 移除了草稿内容，使发布的文章质量更高 更一致的元数据格式 - 标准化了所有文章的前置信息 这种结构化的改进不仅对读者有利，对我自己也是有帮助的。当我继续写作时，这个标签系统将帮助我思考文章的分类和主题，使我的博客内容更加有条理。 未来计划 在这次重构的基础上，我计划继续改进我的博客： 可能考虑按标签或主题组织一些精选文章合集 进一步优化博客的视觉设计，使其更加现代化 添加更多互动元素，如评论系统和社交分享功能 通过这次重构，我重新认识到了博客作为个人表达和知识分享平台的价值。希望这些改进能让我的内容对读者更有帮助，也能激励我继续写作和分享。 感谢GitHub Copilot的协助，让这次重构变得简单而高效。技术的进步确实为内容创作者带来了新的可能性。 这篇blog完全由Copilot生成。

2025的某一天

这一天是2025年7月19日，星期六。 2025进入了炎热的夏天，但我却不知为何，感觉到自己总是在被时间推着走。 似乎写一篇blog记录下自己的生活是一个打破现状的最简单也最直接的方式。 今天是一个寻常的周末，看到copilot给我的markdown文件给出的提示，也挺好笑的。 因为自己有些习惯熬夜，故事的时间总归要回到前一天晚上开始，不然今天睡到十一点也少了太多可以说的东西。 老婆还是坚持着早上去游泳，但是锻炼一段时间还是没有减重的效果，仿佛有些太残忍了。今天上午游完回家的时候，还因为收我的雨伞误伤了自己。收伞的时候弹到自己的上腹部，把自己都快疼懵了。 首先，这个事情的起因有因为互相的温柔。就像我早上起床不想吵醒她一样，她也不想回屋拿自己的伞，怕吵醒我。但实际上，我因为熬夜睡的死死的，根本不会有什么影响。 所以，互相的温柔有时候会带来一些小麻烦。（这是第一句Accept Copilot的建议） 然后，老婆一直在犹豫是不是要去医院看看。还用雨伞模仿了一下冲击力，发现墙面的泥子都被伞把给冲破了。我也在指导下实验了一次。 很好我们的房子又多了两处创伤。 为了安抚她的情绪，我想到，看了这么多的稀奇古怪的新闻，也没听说谁被雨伞给打死的。你要是真内脏受伤扑街了，恐怕也要上新闻，这样你也就出名了！ 确实她觉得很好笑。 下午我们还是去医院挂了号，外科没有挂CT的号，要排队等到下周才能做检查，要是想拍片还是要去急诊。所谓的急诊，我们还是要预先分诊、挂好、二次分诊、看医生、开检查单、去拍片、再回来等结果。在排队的时候，老婆说后悔了。好想逃，不想再排队了。我说流程这么麻烦的原因，大概是真的急诊应该是被救护车拉来，小推车推着进来的才不需要什么排队挂号。 最后拍完片还要等一小时。我们还是出去溜达一下。附近的瑞幸咖啡没有座位，我们热的慌，最后逃入了永和大王。老婆点了一份去冰柠檬红茶，我要了一个黑椒香肠蛋饼和一份看起来是新品的胡萝卜豆汁。 结果就是我们等了十五分钟还是没等到。我只能去前台催促。催促果然是有效的，一分钟后就端上来了。其实我早就看到我们的饮品做好了，放在后台的桌子上。倒是柠檬红茶真的按照备注去冰了，可却难喝的不行。比我点的新品差多了。我说要么我们还是去Family Mart再买点饮料吧。老婆说“你真好”。我觉得莫名其妙，就是去买个饮料罢了。 根据我在永和大王工作的网友介绍，只要告诉他们你要投诉他们，他们就会毕恭毕敬地给你退餐费，求你不要投诉。 因为这会影响他们每两个月一发放的奖金。 当然，检查结果没什么问题。于是我们回打浦桥吃了一顿日料。因为不是很饿，我就点了毛豆和芥末章鱼，外加一瓶一番榨的啤酒。老婆终于可以吃顿好的三文鱼刺身和甜虾了。饭饱酒足我们去公园找阿姨和小宝。回家我有点点醉醺醺，倒头就睡到七点。晚饭也没吃。起床发现之前买的电影票快要开场了，我想还是快点出发吧。于是我们匆匆忙忙地出门，赶到电影院看了姜文的《你行你上》。 影片结束后我问老婆打几分？她给了7分，我给了6分。我说我觉得之前的姜文电影总是在讽刺或者暗示些什么。我总归觉得他不应该拍这种类型的电影。中途我会有些片段觉得不想看下去，点亮手机看了两次时间。我怀疑他是被裹挟了，又怀疑是不是江郎才尽。转头又觉得是不是想太多了，为啥人家不能拍自传式的电影呢？其实作为一部商业电影，这个整片看下来，也没有什么不好的地方。我说这部电影与其说是郎朗自传，不如说是郎朗父亲的自传。大半部分的重心和描写都在姜文饰演的父亲身上。这是一个典型典型典型到极致的中国式的家长。我对这种家长制度的厌恶是从社会上习来的。 但你要说我有什么办法，抱歉，也没有。 如今为人父，虽然还没开始做什么思想教育，但是对一些行为却也能感同身受。自己的孩子在自己眼中做了“错事”，当然想要纠正。 “父母之爱子，为之计深远”。 从来都如此的。

2024-07-07 生活日常回忆游戏

2024第二季度总结

不知不觉，现在又已经7月份了，来总结下这三个月的生活吧。 这次我用其他的分类方式来写这个季度总结，不再按照月份来写。 游戏 翻翻照片发现自己这个月玩的游戏还不少。本来在6月21号之前都是在等《艾尔登法环》的DLC的，但是这个长草期间，还是玩了不少其他的游戏。 想想自己这三个月居然玩了这么多游戏，只能说导游曹小哥对我的羡慕还真是不无道理。 扫雷 手机上的扫雷是第一个。这个经典游戏，是让自己消磨时间的好帮手。我玩的这个版本是43颗雷的easy模式，主要是medium和hard模式的尺寸也是一样的，开局很难找到突破口。让本来就有可能是运气游戏的这个运气游戏更加恼人。 自己的通关记录从1分钟多，不断压缩到了59秒，55秒，50秒，乃至最后的49秒。我想这个已经是自己的极限了。后面的死亡二选一，真的很难顶。 也有一些其他的Google Play益智类游戏，比如找茬、占领地盘、卸螺丝等，也玩了一些时候，不过都没有扫雷让我花费如此之多的时间。 最后自己生气地卸载了这个killing time的游戏，到此为止了。 金铲铲和云顶之弈 在此之后，金铲铲进入我的视线，从一开始玩了不知道啥，可能是斗枪吧，到第三把玩到灵魂莲华羁绊，慢慢地上手了这个游戏。就在7月7日的今天，我还凭借着灵魂莲华羁绊，拿到了一个第三名。最近的一把，老弟给我的天将羁绊，结合随机的尊者羁绊，又吃了一把鸡。现在已经到达了流光翡翠3 70胜点。 中间有和老弟一起玩云顶之弈，但是果真和东哥说的一样，这个和金铲铲真的不是同一个游戏。整个的节奏完全get不到，现在也放弃了。毕竟电脑上还有那么多好玩的游戏不是吗。 全面战争：三国 全战三国这个，是自己玩欧陆风云4、文明6和三国志12，玩腻了之后想到的。因为2019年（貌似是？）刚出的时候我就买了这个游戏，想来觉得自己好像一直不太会玩，这次要不试一试？真的来一把匡扶汉室！ 可当我真的玩到大后期的时候，才发现自己居然有一个存档已经打到了称王称帝的阶段。自己是什么时候玩的这个呢？我怎么不记得了呢！ 玩过几把曹刘之后，也就觉得腻了，想自己写一个随机的mod出来，类似于某个集成大mod的一个“紫虚幻境”的功能，但是发现，所谓的游戏，所谓的代码真的读起来太过于晦涩难懂了。我突然觉得我们公司的项目代码还是太容易读懂了。对于lua的脚本开发，还有mod作者的奇奇怪怪的代码，真的是让人头疼。 星露谷物语 趁着春季大促，我入手了星露谷物语，自己在周末的时候玩了个两三个小时，那天觉得还不错，但是等后面再想玩游戏的时候，却没有那个心思继续玩下去了。这个游戏弟妹在后面入手了，已经玩了一百多个小时，我没想到她会喜欢马赛克游戏，让我推荐一些游戏，按照之前玩过的那些类似《植物大战僵尸》、《杯杯倒满》的风格，真的是想不出来。 杯杯倒满 说到杯杯倒满，这个开奶茶店的游戏。恰恰和最近的manner咖啡店事故让人觉得细思极恐。manner的咖啡店员工却是像是压力爆炸的小熊小狐狸一样，而一个店面日销售额不够5000元的情况下只配备一名员工，可没有其他员工给你安抚情绪，给你搭一把手拉你起来。 等我完成了第一个阶段的杯杯倒满游戏之后，就弃坑了这个游戏。谁也不想在白天打一份工，下了班再打一份吧？ DNF手游 早在5月21日的时候，这个游戏就上线了。这也是在法环DLC出之前的空档期才回去玩的。我的亲爱的网友们也纷纷入了坑，然后练到满级，玩了几天就纷纷出坑了。到最后只有高仿继续玩了下去。 中间我也出坑了几天，卸载游戏。因为觉得似乎已经没有什么好提升，好玩的了。其他的人出坑理由又是什么呢？花费太多时间、没有深渊出货、又或者纯纯单机、纯纯氪金佬的游戏，根本没有什么乐趣了。大家来完全冲着情怀，然后品尝了一口，嗯，就是这口翔的味道！然后就和端游一样弃坑了。或者还有在玩端游的，也是已经养一个耗费巨大精力的号了，不想再养一个了。 我在游戏出阿修罗职业之后，又重新来玩了。等自己真的氪了一点金，又发现这个真的是个无休无尽的坑。提升是没有止境的，玩这种数值游戏只能获得空虚，空虚和空虚。 艾尔登法环DLC 等到6月底，终于迎来了法环DLC的发布，意料之外的是老婆对DLC似乎更加有热情。在前期帮我探图、推剧情，帮我打了牢大、满月骑士等boss，甚至还帮我剪了几个直播视频上传到B站上去。 但是不得不承认自己在有段时间还是有点厌倦这个DLC的。毕竟劳资已经一周目当过王的男人了，为了进入DLC也鸭子乐秒了蒙格，一路过关斩将来这儿的，却被幽影地的小兵砍的抱头鼠窜，实在是让人不爽。 等到过了一个星期之后，自己终于推进主线到了拉塔恩，然后就被对方无休止的疯狂进攻打懵了。不是很习惯这种连续四连、五连甚至七八九十连招攻击的boss。然后就转身投入了洗点、寻找轮椅逃课的道路。 找了拒绝的刺，放弃了癫火调香瓶、试了各种武器和各种大哥，终于还是选择了盾戳流派。发现自己有指纹盾，也发现自己没有黄金粪金龟（因为在小号上），真的可能盾戳就是给我的最好选择吧。 然而我却忘记了强化满级我的盾戳，以至于上周四晚上打了几个小时都各种功亏一篑。因为没有防御强度，每次拉塔恩急风骤雨的攻击，都打的我喘不过气来。等我下播之后，才想起自己没有强化盾牌到满级这个事情。
